# OppiEduAI

## 🎯 Project Goals

- Provide **free Finnish language education** for everyone.
- Support migrants and newcomers in Finland with accessible learning tools.
- Enable **offline AI‑powered exercises**, dialogues and vocabulary training.
- Build a sustainable, open and community-driven educational platform.
- Develop a modern, fast and minimal UI that works on any Android device.

---

## 📱 Features

- AI‑generated dialogues and exercises (offline-capable).
- Vocabulary practice with examples and pronunciation.
- Grammar explanations tailored for beginners.
- Clean, minimal interface optimized for mobile.
- Works without internet connection.
- No ads, no subscriptions, no tracking.

---

## 🧠 Technology Stack

- **.NET MAUI** (Android)
- **Local AI inference** (WebLLM / WebGPU-ready architecture)
- **C# / Blazor Hybrid**
- **Cloudflare Pages + Workers** for backend expansion (planned)
- **Open educational content** based on Finnish language learning materials
